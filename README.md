# Grand Prix

Course de Formule 1 en 3D, directement dans le navigateur.

**Jouer : https://anthonypitt49.github.io/grand-prix/**

- Dix circuits : Monaco, Montréal, Monza, Silverstone, Spa, Zandvoort, Interlagos, Singapour, Spielberg, Hungaroring.
- Une saison complète avec le barème de points de la Formule 1.
- Des courses en ligne entre amis : un joueur crée une salle et donne le code, les autres le rejoignent. Aucun compte n'est nécessaire.

Clavier : W ou flèche haut pour accélérer, S pour freiner, A et D pour tourner, C pour la caméra, Échap pour la pause.

Les noms d'équipes et de circuits sont des références réelles. Les marques de sponsors visibles dans le jeu sont inventées.
